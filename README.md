# Вандроўе — пашпарт адкрыццяў па Беларусі

Учебный авторский проект для задания RS School Landing Page, часть 1.

## Идея

«Вандроўе» предлагает маршруты по Беларуси в формате личного паспорта открытий: путешественник выбирает место, отправляется в дорогу и оставляет свою заметку или символический штамп. Концепция вдохновлена механикой коллекционирования впечатлений, но не использует чужие название, логотип или иллюстрации.

## Страницы

- `index.html` — главная страница;
- `catalog.html` — каталог маршрутов.

## Проверка

- Деплой: https://23boom23.github.io/rsschool-landing-page/
- Каталог: https://23boom23.github.io/rsschool-landing-page/catalog.html
- Разметка обеих страниц проверена W3C Validator без ошибок.
- Адаптивность проверена на ширине 1440px, 768px и 380px.

## Структура

- `scss/` — исходные SCSS: токены, базовые правила, компоненты и секции разнесены по назначению;
- `css/styles.css` — собранный развёрнутый CSS и его source map;
- `js/modules/` — независимые модули темы, навигации, фильтров и модального окна;
- `js/data/` — данные карточек маршрутов;
- `assets/images/` — фотографии с открытыми лицензиями, указанные в [CREDITS.md](CREDITS.md);
- `assets/landmarks/` — авторские SVG-иллюстрации маршрутов.

## Сборка стилей

SCSS собирается без фреймворков и без минификации:

```bash
pnpm dlx sass@1.93.2 scss/main.scss css/styles.css --style=expanded --source-map
```

Проект использует семантические HTML, SCSS и чистый JavaScript. Для локального просмотра достаточно открыть `index.html` в актуальной версии Google Chrome.
