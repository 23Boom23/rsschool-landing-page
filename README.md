# Вандроўе — пашпарт адкрыццяў па Беларусі

Учебный авторский проект для задания RS School Landing Page, часть 1.

## Идея

«Вандроўе» предлагает маршруты по Беларуси в формате личного паспорта открытий: путешественник выбирает место, отправляется в дорогу и оставляет свою заметку или символический штамп. Концепция вдохновлена механикой коллекционирования впечатлений, но не использует чужие название, логотип или иллюстрации.

## Страницы

- `index.html` — главная страница;
- `catalog.html` — каталог маршрутов.

Проект написан на семантических HTML, CSS и чистом JavaScript, без фреймворков и сборки. Для локального просмотра достаточно открыть `index.html` в актуальной версии Google Chrome.
